# Hashward

**Smart contract audits with a proof of concept. EVM and Solana.**

We try to *drain* it before anyone else can. Two reviewers read the code. If a bug can
move funds, the report includes the transaction that does it — and we rerun that
transaction after you patch.

- **Scope** — contract review, economic review, fuzzing and proofs, fix retest
- **Chains** — EVM (Solidity, Vyper), Solana (Rust, Anchor), Move
- **Terms** — one to three weeks, flat price fixed before the engagement starts
- **Evidence** — every exploitable finding ships with a runnable proof of concept

## What we build

- **Contract audits** for EVM, Solana and Move. Two reviewers read the code, every
  exploitable finding ships with a runnable proof of concept, and the retest after
  your patch is part of the engagement.
- **Research** on protocol invariants, oracle design, bridge messaging and the
  economic assumptions that hold a protocol together.
- **Open-source tooling** for automated smart-contract review, released per project
  as it is finished. The code is not in this organisation's public repositories.
